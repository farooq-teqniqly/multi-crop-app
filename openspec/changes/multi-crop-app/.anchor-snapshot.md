# Multi-crop image export

## Problem
Cropping several regions out of one image today means repeating open/crop/save/rename in a general image editor for every region.

## Outcome
From one opened image, a user visually marks up to 20 regions and exports every region as its own correctly-named image file in one action.

## Primary user
A single local user who has an image and wants several sub-images cut from it.

## Core workflow
Open image -> draw crop rectangles on it -> (optionally resize/delete, see them mirrored in a list) -> pick a save folder -> click Crop -> get one file per crop area.

## In scope
- Open an image (jpeg/png/gif)
- Draw/resize/delete crop rectangles with per-area color coding
- Max 20 crop areas
- Crop list synced with canvas (select or delete from either side)
- Folder picker for save location
- Export all crop areas as files named [imageName]_[color].[ext]

## Out of scope
- Editing the base image (rotate/filter/etc.)
- Multi-image batches
- Cloud storage
- Undo/redo history
- Non-Chromium browser support

## Assumptions
- Color is the sole visual distinguisher for crop areas (not numbered labels)
- File System Access API (Chromium-only) is acceptable for this local single-user tool
- Output format matches the source image's extension
